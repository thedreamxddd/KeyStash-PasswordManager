# KeyStash - Dissertation Password Manager

## About this Project
Passwords are a vital part of our day-to-day lives and a fundamental component when using the internet, ranging from using passwords to secure vital information such as banking details to using a password to access an online e-commerce website. However, a large proportion of online users are not aware of correct password handling methods and are unable to determine whether a password is secure. Research shows that a large proportion of users are mishandling their passwords in ways that make them vulnerable to cyber attacks. This dissertation project aims to mitigate this problem by providing a suitable Password Management tool for users to use as intended or create their own with the program as a template to edit.

## 1. How to use "KeyStash"
### 1.1. Method 1
In order to use the "KeyStash" Password Manger as intended follow these steps:
  - Locate "KeyStash.zip" in the GitHub Repository.
  - Unzip the "KeyStash.zip" file in your desired directory.
  - Make sure that the folder contains "libsodium.dll" and "Dissertation Project - Secure Password Manager.exe".
  - Run the .exe file
  - The "Master password" for the Password Manger is "password".
